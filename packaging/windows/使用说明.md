# 多部门文档自动合并系统

## 快速开始

1. 解压整个文件夹，在电脑上安装 64 位 Python 3.12，安装时启用 pip 和 Tcl/Tk。
2. 双击“启动软件.cmd”。首次启动将使用 wheelhouse 内的安装包创建本地虚拟环境并安装依赖。
3. 在窗口中选择原稿、副本目录和合稿保存位置，点击“开始合并”。

合稿、冲突报告和变更日志会保存到选定的位置。建议将合稿放在副本目录之外。

## 命令行使用

在本目录打开 PowerShell，首次启动完成后执行：

```powershell
.\.venv\Scripts\python.exe -m mddm.run_merge "原稿.docx" "副本目录" -o "合稿.docx"
```

用 `.\.venv\Scripts\python.exe -m mddm.run_merge --help` 查看参数。
